# 🍥 Naruto vs Sasuke Hand Tracking AR

An immersive AI-powered Hand Tracking AR experience inspired by **Naruto** and **Sasuke**, built using **MediaPipe Hands, HTML5 Canvas, CSS3, and JavaScript**.

Track your hand movements in real time and unleash anime-inspired chakra effects with dynamic hand detection, glowing skeletons, and interactive visual animations.

## 🚀 How To Use

1. Open the website.
2. Allow webcam permission.
3. Show your hands in front of the camera.
4. Open your left hand to activate Naruto's chakra.
5. Open your right hand to activate Sasuke's chakra.
6. Enjoy the real-time anime visual effects.

---

## 🌟 Main Highlights

### ✋ Hand Tracking

Tracks up to two hands simultaneously using MediaPipe Hands.

### 🍥 Naruto Effect

Displays Naruto chakra animation when the left hand is opened.

### ⚡ Sasuke Effect

Displays Sasuke chakra animation when the right hand is opened.

### 💙 Neon Skeleton

Renders glowing blue hand landmarks and connections.

### 🎥 Video FX

Anime effects are rendered using transparent MP4 overlays.

### ⚡ Smooth Animations

Real-time transitions with responsive performance.
